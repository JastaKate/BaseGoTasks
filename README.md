# GoFlix

проект с небольшими задачами на синтаксис Go - кинотеатр GoFlix.

## Запуск

```sh
go run .
```
Команда запускает все примеры из `main.go`

## Задачи

- `tickets.go` — расчёт цены с надбавками, формирование чека и проверка возраста
- `access.go` — проверка блокировки, возраста и типа подписки
- `schedule.go` — расписание трёх залов, поиск фильма и подсчёт рун
- `duplicates.go` — удаление повторов с сохранением порядка, без мапы
- `slices.go` — дополнительные упражнения: сумма и фильтрация элементов
- `main.go` — вызовы функций с примерами исходных данных
